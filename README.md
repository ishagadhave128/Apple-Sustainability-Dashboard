# Apple Sustainability Dashboard

## Project Overview
This Power BI project analyzes Apple's sustainability performance, with a focus on greenhouse gas emissions.

## Objectives
- Analyze greenhouse gas emissions.
- Explore sustainability performance.
- Present environmental data using Power BI visualizations.

## Tools Used
- Microsoft Power BI
- Data Analysis
- Data Visualization
